# CCW Analysis Notes

This folder stores qualitative and quantitative interpretation of CCW backtest results.

Raw generated outputs remain under `runs/`. Analysis documents should summarize findings, hypotheses, comparisons, and caveats without replacing the underlying run artifacts.

Use these notes to separate research interpretation from core strategy, architecture, and implementation documentation. When reviewing results, distinguish clearly between:

- raw frictionless backtest results;
- execution-friction-adjusted sensitivity results.

## Documents

- `weekly_btc_baseline.md`: baseline weekly BTC covered-call interpretation and comparison notes.
- `execution_friction.md`: execution-friction sensitivity model and limitations.
