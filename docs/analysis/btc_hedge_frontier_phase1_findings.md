# BTC Hedge Frontier Phase 1 Findings

This file is the stable documentation entry point for Hedge Frontier Research Phase 1.

Generated findings are written to:

- `analysis/generated/btc_hedge_frontier_phase1_findings.md`
- `analysis/generated/btc_hedge_frontier_phase1_findings.json`

## Scope Reminder

This phase is an analysis-only fixed hedge study over existing BTC CCW baseline cycles.

It ignores funding, basis, liquidation, borrow, slippage, margin, leverage, and intracycle mark-to-market mechanics.

## Reading Discipline

Use the generated findings in three layers:

- Observations: measured output changes.
- Interpretations: conservative implications.
- Hypotheses: candidates for later research.

Do not treat Phase 1 as proof of live hedge economics.
